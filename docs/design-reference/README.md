# Design reference for Home

Exported from the "COUPI and Home" page of the team's design canvas. These files are reference only: copy the look, not the file format.

- `Coupi.dc.html`: the COUPI character as one SVG with seven moods (calm, excited, attentive, sleepy, listening, thinking, relaxed). `{{...}}` holes are template values: `show*` entries are `"inline"` or `"none"` depending on the mood; see the script at the bottom of the file.
- `HomeStates.dc.html`: Home layout A in five states (first, normal, problem, quiet, night).
- `CoupiHead.dc.html`: the Inside COUPI's head settings screen.
