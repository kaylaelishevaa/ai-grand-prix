The live-call backend was ported from `kaylaelishevaa/ai-grand-prix` commit `fb179e0670aea97dd1e16d5d149815a42a7fb38c`. The original tool names and camera/try-on behavior are retained. Every genuine user turn, during and after the first interview, now uses `/api/call`. Realtime handles speech; the structured call result controls recommendations, memory and proposed decisions.

Routes:

| Route | Input | Response |
| --- | --- | --- |
| `GET /api/voice/status` | Same app session cookie | `{ ready, offline, model, catalogCount, reason? }`. Presence of a key is not proof of credits/model access. No provider request occurs. |
| `POST /api/voice/session` | `application/sdp`; audio-only WebRTC offer, at most 65,536 bytes | Raw `application/sdp` answer, or a short safe JSON error. |
| `POST /api/products/search` | JSON `{ query, category, max_price }`; categories `all`, `makeup`, `clothes`, `desk`, `glasses`; at most 4,096 bytes | Up to three sourced listings, historical-reference disclosure and Coupang search URL. This is local retrieval. |
| `POST /api/products/world` | JSON `{ action:"search", query, max_price }` or `{ action:"open", skuId }` | Same-world catalog facts with explicit provenance with `catalog_namespace:"world-simulation"`, or a fresh eligibility refusal. Search/open never calls a model, changes XP or places a decision/order. |

POSTs require an exact same-origin `Origin` and reject `Sec-Fetch-Site: cross-site`. The session uses server-only `OPENAI_API_KEY`, and `OPENAI_REALTIME_MODEL` or the teammate default `gpt-realtime-2.1`. No credential is sent to the browser. `DEMO_OFFLINE=1` reports `ready:false, offline:true` and refuses a session before any network request; local catalog retrieval remains available.

`data/teammate-catalog.json` contains the teammate’s 18 sourced product references, with original provenance URLs and historical price limitations. Only local image paths were moved to `/live-call/products/`. Seventeen priced records are adapted into the shared catalog with exact IDs, historical-price metadata, local image paths and empty review lists. The unpriced lamp remains reference-only. Seeded reviews never move across provenance; unknown delivery cannot earn a fastest badge or select Rocket/Dawn checkout. Order receipts preserve the source and price basis.

Each new session receives `sanitizeProfileForAI` output (at most 32 active memory lines), plus permitted current district names and their exact eligible product IDs/names. It never receives the raw profile, diary entries, quarantine log, decisions or ownership dates. District context is withheld when its source memory has been erased or excluded. Erased and excluded memories do not enter a new handshake. Product retrieval also excludes owned reference IDs and quarantined category mappings. Changes made during a running WebRTC conversation take effect on the next session; previously transmitted context cannot be unsent by this handshake route.

The four original tools remain `search_products`, `set_tryon`, `product_action`, and `look_at_camera`. Two separate tools connect the call to the world journey: `search_world_products` retrieves the exact eligible catalog, source metadata and available review IDs, while `open_world_product` opens the existing verdict/evidence/delegation sheet. World results also have a local Details button. The original sourced references retain separate evidence: a photographed lamp or lipstick is never equated with a synthetic SKU merely because its category looks similar, and no seeded reviews are attributed to a sourced listing.

Before opening a world product, the iframe rechecks eligibility against the current server profile, stops microphone/camera, then posts `{type:"coupi-live-call-product", namespace:"world-simulation", skuId}` to the exact same-origin parent. The parent checks iframe identity, namespace and current eligibility again, waits for queued transcript writes, and opens the shared product flow. This action does not add, approve or buy anything. Sourced-reference Save remains a reversible local call bag. A genuine shopping request can propose an eligible priced reference through `/api/call`; it then reaches the shared Decisions and mock checkout with its original identity. The peer connection closes when the call ends; as in the original backend, no call ID or separate remote-end endpoint is exposed.

A final genuine user speech or typed statement is the sole trigger for a call turn. The parent serializes `/api/call` requests, correlates their request IDs and sends a whitelisted result back; profile, diary and raw image bytes never enter that reply. The embedded session disables automatic VAD replies and speaks only after that checked result arrives. `resolve_shopping_request` waits for the same pending result instead of creating a duplicate request. Only explicitly supported statements can become sourced memory, with a dated call source. Assistant speech, camera metadata, partial transcripts and synthetic UI prompts are excluded. Later world generation reads the latest saved profile; a live conversation does not silently rebuild a district. Deleting those memories changes the next generation context and the next call handshake.

No audio, camera frame, SDP, profile content or key is logged. The server logs handshake model/status/latency and marks token usage unavailable because the SDP response has no usage totals. Upstream error details are bounded and replaced with safe funding/rate/access messages.

`npm test` includes the teammate’s original server and voice-client suites through `tests/teammate-voice.test.ts`. Their `.mjs` fixtures run against the ported backend and `/public/live-call/voice-call.js`, with fake fetch, fake WebRTC and fake microphone objects. No camera, microphone, credential or provider is used by these tests. The world bridge tests cover exact seeded evidence, namespace separation, current ownership/quarantine, erased-source filtering, no diary leakage, offline local retrieval and stopping media before the parent event. A catalog consistency check also verifies that local asset namespacing never rewrites real retailer URLs.

The first interview is optional and interruptible. Shopping/vision requests preserve its question index. An explicit resume restores the pending question; early finish requires safe, surviving user-sourced context. Greetings and unrelated talk do not consume one of the five questions. The fifth actual answer opens World immediately. A failed call turn offers a retry with the original ID; photos are retained only transiently in the client retry state and discarded on leaving the call. Camera input is a single opted-in current JPEG per finalized turn, bounded before upload.
