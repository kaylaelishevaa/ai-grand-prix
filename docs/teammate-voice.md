The live-call backend was ported from `kaylaelishevaa/ai-grand-prix` commit `fb179e0670aea97dd1e16d5d149815a42a7fb38c`. The original tool names and camera/try-on behavior are retained. First-interview and typed calls continue to use `/api/call`.

Routes:

| Route | Input | Response |
| --- | --- | --- |
| `GET /api/voice/status` | Same app session cookie | `{ ready, offline, model, catalogCount, reason? }`. Presence of a key is not proof of credits/model access. No provider request occurs. |
| `POST /api/voice/session` | `application/sdp`; audio-only WebRTC offer, at most 65,536 bytes | Raw `application/sdp` answer, or a short safe JSON error. |
| `POST /api/products/search` | JSON `{ query, category, max_price }`; categories `all`, `makeup`, `clothes`, `desk`, `glasses`; at most 4,096 bytes | Up to three sourced listings, historical-reference disclosure and Coupang search URL. This is local retrieval. |
| `POST /api/products/world` | JSON `{ action:"search", query, max_price }` or `{ action:"open", skuId }` | Same-world synthetic catalog facts with `catalog_namespace:"world-simulation"`, or a fresh eligibility refusal. Search/open never calls a model, changes XP or places a decision/order. |

POSTs require an exact same-origin `Origin` and reject `Sec-Fetch-Site: cross-site`. The session uses server-only `OPENAI_API_KEY`, and `OPENAI_REALTIME_MODEL` or the teammate default `gpt-realtime-2.1`. No credential is sent to the browser. `DEMO_OFFLINE=1` reports `ready:false, offline:true` and refuses a session before any network request; local catalog retrieval remains available.

`data/teammate-catalog.json` contains the teammate’s 18 sourced product references, with original provenance URLs and historical price limitations. Only local image paths were moved to `/live-call/products/`. These records are **not merged** into the synthetic scene catalog or seeded review corpus. Their prices, product IDs, reviews and delivery facts must not be borrowed from that separate database.

Each new session receives `sanitizeProfileForAI` output (at most 32 active memory lines), plus permitted current district names and their exact eligible product IDs/names. It never receives the raw profile, diary entries, quarantine log, decisions or ownership dates. District context is withheld when its source memory has been erased or excluded. Erased and excluded memories do not enter a new handshake. Product retrieval also excludes owned reference IDs and quarantined category mappings. Changes made during a running WebRTC conversation take effect on the next session; previously transmitted context cannot be unsent by this handshake route.

The four original tools remain `search_products`, `set_tryon`, `product_action`, and `look_at_camera`. Two separate tools connect the call to the world journey: `search_world_products` retrieves the exact eligible synthetic catalog and seeded review IDs, while `open_world_product` opens the existing verdict/evidence/delegation sheet. World results also have a local Details button. The original sourced references remain separate: a photographed lamp or lipstick is never equated with a synthetic SKU merely because its category looks similar, and no seeded reviews are attributed to a sourced listing.

Before opening a world product, the iframe rechecks eligibility against the current server profile, stops microphone/camera, then posts `{type:"coupi-live-call-product", namespace:"world-simulation", skuId}` to the exact same-origin parent. The parent checks iframe identity, namespace and current eligibility again, waits for queued transcript writes, and opens the shared product flow. This action does not add, approve or buy anything. Sourced-reference Save remains a reversible local call bag; it does not create synthetic Decisions. The peer connection closes when the call ends; as in the original backend, no call ID or separate remote-end endpoint is exposed.

Only final genuine user speech/typed call statements are persisted as memory, with a dated call source. Assistant speech, camera metadata, partial transcripts and synthetic UI prompts are excluded. Later world generation reads the latest saved profile; a live conversation does not silently rebuild a district. Deleting those memories changes the next generation context and the next call handshake.

No audio, camera frame, SDP, profile content or key is logged. The server logs handshake model/status/latency and marks token usage unavailable because the SDP response has no usage totals. Upstream error details are bounded and replaced with safe funding/rate/access messages.

`npm test` includes the teammate’s original server and voice-client suites through `tests/teammate-voice.test.ts`. Their `.mjs` fixtures run against the ported backend and `/public/live-call/voice-call.js`, with fake fetch, fake WebRTC and fake microphone objects. No camera, microphone, credential or provider is used by these tests. The world bridge tests cover exact seeded evidence, namespace separation, current ownership/quarantine, erased-source filtering, no diary leakage, offline local retrieval and stopping media before the parent event. A catalog consistency check also verifies that local asset namespacing never rewrites real retailer URLs.
